Ice Zoo Board App is the native iOS and iPadOS counterpart to the Ice Zoo Board web platform. It serves as both a high-fidelity spectator display and a secure, authenticated operator controller for managing live ice sports games.

### Key Features

- **Real-Time Sync Engine:** Utilizes Firestore `AsyncStream` and Snapshot Listeners alongside RTDB for precise clock interpolation and multi-device state synchronization.
- **Dual Modes:** Provides a responsive, iPad-optimized spectator view and an authenticated operator mode for managing scores, automatic penalties, and game clock.
- **Dynamic Clock Interpolation:** Implements high-frequency local clock updates for smooth visual ticking without overwhelming backend resources.
- **Tech Stack:** Built entirely in Swift and SwiftUI, leveraging the modern Firebase SDK for robust real-time capabilities.
