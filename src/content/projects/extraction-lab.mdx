Extraction Lab is a founder-led project developing a professional coffee intelligence platform. It utilizes local AI (Gemma 4) for advanced extraction analysis and dial-in assistance for coffee professionals and enthusiasts.

### Key Features

- **Local AI Integration:** Powered by Gemma 4 for intelligent extraction analysis.
- **Deep Apple Ecosystem Integration:** Supports Live Activities, Dynamic Island, and includes an Apple Watch companion app.
- **Smart Inventory Management:** Features peak-flavor alerts to ensure coffee is enjoyed at its best.
- **Professional Sensory Data Models:** Implements sophisticated data visualization using radar charts for sensory profiles.
- **Tech Stack:** Engineered using Swift and SwiftUI for a native, high-performance experience.
